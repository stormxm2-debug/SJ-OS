## 2단계 결과 (v1.0.55, 검토 대기)

- 청구 목록: 같은 DOM이 PC(640px 이상)에서는 6열 간결 목록, 375px 모바일에서는 카드로 쌓임(`ClaimRecordList.tsx`).
  기본 필드: 작업 선택 / 진료일·병원(약국) / 상병·코드 / 진료유형·입원일수 / 수동 청구 상태.
  수술(추정)·독감 약물 담보 확인 대상·고액 본인부담 배지는 목록에 유지.
- 약물 전체·성분·투약일수·좌우·세부 처치·수동 확인일은 행별 **상세 보기**로 펼침. 원자료에 없으면 미확인/미제공 표시.
- 상단: 검색 → 유형/상태 필터 → "현재 목록 N건 인쇄 / PDF"(보조: 상태 새로고침) + 인쇄 범위 한 줄 안내(선택과 무관, 현재 보이는 목록 전체).
- 선택했을 때만 "선택 N건" 툴바(주: 청구 완료로 저장 / 보조: 미청구·미확인으로 저장). 미선택 시 한 줄 안내만.
  전체 선택은 일부 선택 시 indeterminate. 200건 제한·saving/loading 차단·숨겨진 선택 제외 보존.
- 불러오기 실패 시 오류 + **다시 불러오기**. 저장 실패 시 오류·선택 유지, 서버 성공 응답 후에만 상태 갱신.
- 검색·필터·선택·상세 펼침 상태는 `HealthRecordWorkspace`(단일 인스턴스)가 보유 → 탭 왕복 유지,
  requestId/result 변경 시 선택·펼침 초기화.
- 저장 API·키 생성·필터·인쇄 서비스·데이터 집계는 변경하지 않음. 3·4단계는 대기.

## 1단계 결과

- `ResultReport` 순서: 3탭 → 적용 기간 → **한눈에 요약(KPI 4개, 큰 숫자)** → 확인 권장(추정) 칩 →
  **최근 3개월 고정** 이력 → 접힌 **상세 기록** → 접힌 **자료 기준 안내**.
- `HealthRecordWorkspace`는 탭 패널의 첫 자식으로 단일 인스턴스 유지 → 청구 검색·필터·선택,
  보험사 선택·기준 조회, 실손 입력이 탭 왕복에도 유지됩니다.
- 3탭: 이름 + 짧은 설명(핵심 수치·이력 / 청구 상태 확인 / 기준 조회·AI), 높이 56px, 활성 탭 남색+금색 밑줄,
  ←/→ 키 전환. 활성 탭 안내는 한 줄(13px).
- 기간: "적용 기간 — 요약 수치·상세 기록·청구·가입 검토에 적용" 박스, 선택값과 실제 날짜 범위
  ("조회된 자료 안에서만") 표시. KPI 제목과 상세 기록 제목 옆에 선택 기간 배지.
  최근 3개월 표는 남색 **최근 3개월 고정** 배지 + 실제 날짜 + "적용 기간 버튼과 무관".
- 상세 기록: 하나의 접힌 영역에서 상병별 묶음(기본)/상병 집계/진료순(연도·월)/원자료 선택.
  기존 EpisodeView·DiseaseSummaryView·SpecTable·원본 JSON 모두 유지, 초기 화면 중복 노출 없음.
- 반복 주의문(입원일수 계산, 추정 연결, 확인 권장 신호, 고지 판정 아님)은 "자료 기준 안내"로 모음.
  값 옆 의미(입원 일수(추정), 수술(명칭 기반 추정), 상태 확인 필요/청구 상태 미조회, 날짜 미확인)는 유지.
  청구·가입 검토 탭의 오류·저장 실패·미매칭 안내는 변경하지 않았습니다.
