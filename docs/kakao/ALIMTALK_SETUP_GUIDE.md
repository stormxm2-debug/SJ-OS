# 알림톡(카카오 미팅 안내) 설정 가이드 — 대표님용

미팅 일정을 고객에게 **회사 카카오톡 채널 이름으로 자동 발송**하기 위한 준비 절차입니다.
개발(앱 버튼·발송 서버·자동 리마인더)은 이미 완료되어 있고, 아래 절차가 끝나면 키만 등록해 바로 켤 수 있습니다.

## 진행 순서 (총 3~7일, 비용: 발송 건당 약 8원)

### 1단계. 카카오톡 채널 만들기 (10분 + 인증 1~3일)
1. [center-pf.kakao.com](https://center-pf.kakao.com) 접속 → 카카오 계정 로그인
2. **채널 만들기** — 채널 이름: `SJ INVEST` (프로필 사진은 회사 로고)
3. 채널 관리자센터 → 관리 → **비즈니스 채널 신청** → 사업자등록증 제출
   - 비즈니스 인증이 승인되어야 알림톡 발신프로필 등록이 가능합니다

### 2단계. 솔라피 가입 (20분)
1. [solapi.com](https://solapi.com) 회원가입 → 사업자 정보 등록
2. 콘솔 → **카카오 채널 연동** 메뉴 → 1단계에서 만든 채널 연결
   (채널 관리자 휴대폰 인증 필요 — 발신프로필(pfId)이 생성됩니다)
3. 콘솔 → **발신번호 등록** — SMS 폴백용 회사 대표번호 (통신서비스 이용증명원 필요할 수 있음)
4. 콘솔 → **API Key 관리** → API Key + API Secret 발급 (아래 6단계에서 사용)
5. 충전: 우선 1만 원이면 알림톡 약 1,200건

### 3단계. 템플릿 심사 신청 (등록 10분 + 심사 1~3영업일)
솔라피 콘솔 → 알림톡 템플릿 → 아래 3종을 그대로 등록하고 심사를 신청하세요.
변수 표기 `#{...}`는 그대로 두셔야 합니다 (발송 시 자동 치환).

**템플릿 1 — 미팅 확정 안내** (이름: `sj_meeting_confirm`)
```
[SJ INVEST] 미팅 안내

안녕하세요 #{고객명}님, SJ INVEST #{담당자명}입니다.

■ 일시: #{일시}
■ 장소: #{장소}
■ 내용: #{미팅유형}

일정 변경이 필요하시면 이 번호로 연락 부탁드립니다. 감사합니다.
```

**템플릿 2 — 전날 리마인더** (이름: `sj_meeting_remind`)
```
[SJ INVEST] 미팅 리마인드

#{고객명}님, 안녕하세요. SJ INVEST #{담당자명}입니다.
내일 예정된 미팅을 다시 한번 안내드립니다.

■ 일시: #{일시}
■ 장소: #{장소}
■ 내용: #{미팅유형}

내일 뵙겠습니다. 감사합니다.
```

**템플릿 3 — 일정 변경 안내** (이름: `sj_meeting_change`)
```
[SJ INVEST] 미팅 일정 변경 안내

#{고객명}님, 안녕하세요. SJ INVEST #{담당자명}입니다.
미팅 일정이 아래와 같이 변경되었습니다.

■ 변경된 일시: #{일시}
■ 장소: #{장소}
■ 내용: #{미팅유형}

착오 없으시길 바랍니다. 감사합니다.
```

> 심사 팁: 광고 문구(할인·이벤트 등)가 없어야 하며, 위 문안은 정보성 안내라 통과가 잘 되는 유형입니다.
> 반려되면 반려 사유가 콘솔에 표시됩니다 — 사유를 개발 세션에 전달해 주시면 문안을 수정해 드립니다.

### 4단계. 키 등록 (개발/총괄 세션에 전달)
심사 통과 후 아래 값들을 확인해서 전달해 주세요. Supabase 시크릿으로 등록합니다:

| 시크릿 이름 | 값 | 확인 위치 |
|---|---|---|
| `SOLAPI_API_KEY` | API Key | 솔라피 콘솔 > API Key 관리 |
| `SOLAPI_API_SECRET` | API Secret | 솔라피 콘솔 > API Key 관리 |
| `SOLAPI_PF_ID` | 발신프로필 ID | 솔라피 콘솔 > 카카오 채널 연동 |
| `SOLAPI_SENDER_PHONE` | 등록한 발신번호 | 솔라피 콘솔 > 발신번호 |
| `SOLAPI_TPL_MEETING_CONFIRM` | 템플릿 1의 ID | 템플릿 상세 화면 |
| `SOLAPI_TPL_MEETING_REMIND` | 템플릿 2의 ID | 템플릿 상세 화면 |
| `SOLAPI_TPL_MEETING_CHANGE` | 템플릿 3의 ID | 템플릿 상세 화면 |

등록 명령 (총괄 세션용):
```
supabase secrets set SOLAPI_API_KEY=... SOLAPI_API_SECRET=... SOLAPI_PF_ID=... SOLAPI_SENDER_PHONE=... SOLAPI_TPL_MEETING_CONFIRM=... SOLAPI_TPL_MEETING_REMIND=... SOLAPI_TPL_MEETING_CHANGE=...
supabase functions deploy send-alimtalk
```

### 5단계. (선택) 전날 오전 9시 자동 리마인더 켜기
`docs/supabase/SJ_OS_SUPABASE_ALIMTALK_SCHEMA.sql` 하단의 pg_cron 주석을 해제해 실행
(먼저 같은 파일 상단의 alimtalk_logs 테이블 생성 SQL 실행 필요).

## 키 등록 전에도 되는 것
- 일정 카드의 **[카톡 공유]** 버튼 — 폰 공유창으로 미팅 안내 문자를 카톡 방에 바로 보내기 (무료, 즉시 사용 가능)
- **[고객에게 카톡 안내]** 버튼은 키 등록 전까지 "알림톡 설정 전입니다" 안내가 표시됩니다
