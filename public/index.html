가입제안서 담보 자동 엑셀 정리

제안서를 여러 건 올리면 담보를 뽑아 분류하고, 체크한 담보로 합계표와 엑셀 양식을 만들어 드립니다.

📄

눌러서 파일을 고르거나 여기로 끌어다 놓으세요

제안서 여러 개 한꺼번에 가능 · PDF, JPG, PNG
엑셀 양식(.xlsx)을 끌어다 놓으면 양식으로 등록됩니다

    분석된 제안서

    회사명과 보험료가 다르면 고치세요. 같은 회사 파일이 여러 개면 보험료는 합산됩니다.

    양식에 넣을 담보 고르기

    확인 필요 양식에 없는 담보(기본 해제) 분류·구분·일당은 직접 고칠 수 있습니다

    아직 분석한 제안서가 없습니다. 먼저 문서를 올려주세요.

    최종 합계표 (보험료 낮은 순 · 일당 만원)

    위 칸은 회사별 담보 값(직접 수정 가능), 아래 노란 줄은 회사별 합계입니다. 빨간 칸은 일당을 못 읽은 곳이니 직접 입력하세요.

    이 보험의 장점

    제안서끼리 비교해 보험사별 장점을 자동으로 정리합니다. 직접 고쳐도 되고, 고친 내용이 엑셀에 들어갑니다.

    항목별 보험료 (체크한 담보 기준 · 월 보험료와 1일당 받는 금액 · 저렴한 회사부터)

    엑셀 받기

    양식 없이 바로 받기 — A4 가로 한 장: 회사별 담보 표 + 합계 · 페이백 안내 · 이 보험의 장점 (+ 담보목록 시트)

    내 엑셀 양식에 채워서 받기 (회사는 보험료 낮은 순, 합계·페이백·장점은 표 아래에 추가)

    선택된 양식 없음

    아직 계산할 담보가 없습니다. 문서를 올리고 담보를 체크해주세요.
