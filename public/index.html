가입제안서 담보 자동 엑셀 정리

제안서를 여러 건 올리면 담보를 뽑아 분류하고, 체크한 담보만 엑셀 양식에 채워 드립니다.

1. 가입제안서 올리기

📄

눌러서 파일을 고르거나 여기로 끌어다 놓으세요

여러 개 한꺼번에 가능 · PDF, JPG, PNG · 분석 후에도 계속 추가할 수 있습니다
엑셀 양식(.xlsx)을 끌어다 놓으면 양식으로 등록됩니다

    2. 분석된 제안서

    회사명과 보험료가 다르면 여기서 고치세요. 같은 회사 파일이 여러 개면 보험료는 합산됩니다.

    3. 양식에 넣을 담보 고르기

    확인 필요 양식에 없는 담보(기본 해제) 분류·구분·일당은 직접 고치거나 입력할 수 있습니다

    4. 양식 미리보기

    체크한 담보가 아래처럼 채워집니다. 칸을 직접 고쳐도 됩니다(농협처럼 일당을 못 읽은 칸은 여기서 입력).

    5. 최종 합계표 (하루 입원 시 받는 금액, 만원)

    체크한 담보를 전 보험사 합산한 금액입니다. 상황별로 상해·질병을 나눠 계산합니다.

    6. 엑셀 받기

    선택된 양식 없음
