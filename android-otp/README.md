# SJ 인증번호 (OTP 포워더)

보험사 전산 로그인 인증번호를 자동으로 잡아 SJ-OS 서버(`otp-ingest`)로 전달하는
**내부 전용** 안드로이드 앱. FC 폰에 설치하면, 이후 보험사 OTP가 오는 즉시
총무 "인증번호 전달함" 보드에 자동으로 뜹니다. (FC는 손대지 않음)

## 동작
문자 읽기 권한 없이 **알림 접근(NotificationListener)** 하나로 문자·카톡을 모두 캡처한다.
1. **문자(SMS) 알림** — 문자가 오면 메시지 앱이 띄우는 알림에서 인증 키워드(`인증`,`OTP`,`코드` 등) + 4~8자리 숫자 추출
2. **카카오톡 알림톡** 알림에서 동일하게 추출
3. 보험사명을 본문에서 자동 태깅(가능할 때)
4. `otp-ingest`로 `{ token, code, insurer, sender, raw }` POST (기기 토큰으로 인증)

## 권한
- `INTERNET` — 서버 전송
- **알림 접근(NotificationListener)** — 문자·카톡 인증번호 캡처. 앱의 "알림 접근 허용" 버튼 → 설정에서 'SJ 인증번호' ON.
  - 문자/카톡 **알림이 실제로 떠야** 읽힙니다. 해당 앱 알림이 꺼져 있으면 켜주세요.

> ⚠️ **왜 READ_SMS/RECEIVE_SMS 를 안 쓰나?**
> 구글은 문자 읽기 권한을 가진 앱을 스토어 밖(사이드로드)에서 설치하면 "악성 앱 의심"으로
> **하드 차단**합니다(폰 설정으로 못 끔). 그래서 문자 권한을 쓰지 않고, 문자가 오면 뜨는
> **알림**을 읽는 방식으로 바꿔 차단을 피했습니다.

## 설치 (사이드로드)
1. GitHub Actions의 **Android OTP APK** 워크플로우 결과물(`sj-otp-apk`)에서 `app-debug.apk` 다운로드
   - 또는 Actions 탭 → "Android OTP APK" → 최근 실행 → Artifacts
2. FC 폰으로 APK 전송 → 설치(출처를 알 수 없는 앱 허용)
   - 삼성 갤럭시는 `설정 → 보안 및 개인정보 보호 → 자동 차단` 을 먼저 꺼야 설치됩니다.
3. 앱 실행 → **수신 주소**는 기본값 그대로, **기기 토큰**은 SJ-OS 앱 → "인증번호 전달함 → 내 폰 연결"에서 복사해 붙여넣기 → **저장**
4. **"알림 접근 허용"** 버튼 → 설정에서 'SJ 인증번호' ON
   - 안드로이드 13+ 에서 "제한된 설정" 안내가 뜨면: `설정 → 앱 → SJ 인증번호 → ⋮ → 제한된 설정 허용`
5. "테스트 전송"으로 총무 화면에 `000000`이 뜨는지 확인

## 안정성 팁
- 배터리 최적화에서 이 앱을 **예외(제한 없음)**로 두면 백그라운드에서도 잘 동작합니다.

## 로컬 빌드 (선택)
Android SDK가 있는 환경에서:
```
cd android-otp
./gradlew assembleDebug
# 결과: app/build/outputs/apk/debug/app-debug.apk
```

## 구성
- `minSdk 24` / `compileSdk 34` · Kotlin · AGP 8.5.2 / Gradle 8.9
- 권한: `INTERNET` + 알림 접근(런타임 사용자 허용)
- 디버그 서명 APK(내부 배포용). 스토어 등록 불필요.
