---

담보정리 도구 전체를 점검하고 결과를 보고해줘. $ARGUMENTS

점검 항목:
1. 문법 검사 (`node --check` 로 server/*.js, public/app.js)
2. 실제 가입제안서가 있으면 파서 결과(담보 수, 보험료, 분류)를 확인
3. 합계표 계산이 맞는지 확인 (일반/종합/상급/요양/간호간병, 상해·질병)
4. 실제 엑셀 양식에 채워보고 기존 수식이 살아 있는지, 합계표가 하단에 들어가는지 확인
5. 브라우저에서 업로드 → 체크 → 다운로드 흐름과 콘솔 오류 확인

보고 규칙:
- 통과한 것과 실패한 것을 나눠서 표로
- 확인하지 못한 항목은 "미검증"이라고 분명히 적을 것 (통과로 적지 말 것)
