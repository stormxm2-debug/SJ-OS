argument-hint: [제안서 파일 경로들 (@로 첨부해도 됨)]

아래 가입제안서를 분석하고 결과를 보고해줘: $ARGUMENTS

진행 방법:
1. 서버가 꺼져 있으면 먼저 띄운다 (detached 실행, 10초 대기 후 http://localhost:4173 확인)
2. 각 파일에 대해 파서를 돌려 담보 목록, 보험사, 총 보험료, 간병 페이백 여부를 뽑는다
3. 분류 결과를 양식 항목(입원일당/종합병원일당/간병인사용일당/요양병원및의원/통합간호간병/상급·종합 인실)별로 정리한다
4. 최종 합계표(일반/종합/상급/요양/간호간병, 상해·질병 각각)를 계산한다

보고할 때 지킬 것:
- 값이 비어 있거나 "확인 필요"인 항목은 숨기지 말고 따로 모아서 보여준다
- 추측으로 값을 채우지 않는다
- 이전에 확인된 값(고객 엑셀 양식)이 있으면 차이를 표로 비교한다
